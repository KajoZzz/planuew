# 📚 Nieoficjalna Aplikacja Plan Zajęć dla Studentów

Aplikacja umożliwia studentom wygodne przeglądanie swojego planu zajęć.  
Plan jest pobierany automatycznie ze strony uczelni, a użytkownik może dostosować go do swoich potrzeb.

---

## ✨ Funkcje

### **Wybór grupy**
- Wyświetl plan swojej grupy dziekańskiej  
- Dane pobierane automatycznie ze strony uczelni  

### **Własne zajęcia**
- Dodawaj zajęcia spoza oficjalnego planu, np.:  
  - lektoraty języków obcych  
  - przedmioty fakultatywne  
  - koła naukowe  

### **Ukrywanie zajęć**
- Ukrywaj niechciane zajęcia z planu, np. wykłady, na które nie chodzisz
